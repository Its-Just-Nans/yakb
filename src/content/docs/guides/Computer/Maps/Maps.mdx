### PMTiles - https://github.com/protomaps/PMTiles

An open specification for single-file tile pyramids built on compressed Hilbert ordering and queryable via HTTP Range Requests.

To use it:

- expose the (big) `.pmtiles` file on an HTTP server
- query the first 16,384 bytes with an HTTP range request
- decode the header and the metadata which gives you the ranges of the tiles
- fetch the tiles you want with an HTTP range request

Viewer: https://pmtiles.io/
Specifications: https://github.com/protomaps/PMTiles/blob/main/spec/v3/spec.md
